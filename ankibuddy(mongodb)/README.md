# ANKI BUDDY

ANKI BUDDY is a python script for sending and receiving notes via a shared google drive folder

## Installation

Use the install.sh file or run the following

```bash
pip3 install -e .
```

## Usage

To use the UI

```bash
ankibuddy
```

Skip UI and use the options

```

options:
  -h, --help      show this help message and exit
  -s, --send      Uploads your last card to google drive
  -d, --download  Download the most recently added note(s) from the database
  -c, --config    Create config file is one doesnt exist and print the path

```
